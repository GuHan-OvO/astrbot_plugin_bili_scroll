# 我会自己刷B站

她有自己的 B站 日常：自己刷、自己挑、自己看，看完在评论区 @ 你。

AstrBot 插件。不是转发机器人——它按自己的口味选片、评价、互动，并把这些事记下来。

---

## 一、刷 B 站

- **主动看视频**：从收藏夹投喂池、关注更新、关键词搜索、视频池四条路径均衡选片，再评价、点赞 / 投币 / 收藏 / 关注 / 评论
- **收藏夹投喂池**：把视频塞进指定收藏夹（`PROACTIVE_FAV_FOLDERS`，填 media_id 或收藏夹链接），
  Bot 优先看这些；失效视频（`attr != 0`）自动跳过
- **一周分区口味**：最近 7 天按分区汇总观看数与平均评分，交给模型决定搜索词与标题筛选，同时保留自由探索
- **来源按天均分**：收藏夹 → 关注 → 搜索 → 视频池 依次补位（当天第 1 个取收藏夹，第 2 个关注，
  第 3 个搜索，第 4 个回视频池）；分多次触发也承接当天进度，缺候选自动补位
- **看片前标题筛选**：按标题 / UP / 分区 / 简介初筛候选；关注和符合历史口味的直接放行
- **每日自主安排**：依当前人格与活跃度规划当天作息与节奏，可设为休眠结束后生成或固定时刻生成，失败按间隔重试
- **行为安全上限**：评论、私信、发动态、主动浏览只设每日硬上限，不设必须完成的数量；计划模型失败时当天不补造事件
- **可编辑浏览时段**：配置固定主动浏览时间段，保存时校验时长、相邻间隔与休眠冲突
- **跨端活动同步**：把「正在挑选视频」「正在分析视频」同步给绑定主人的 QQ 私聊，行为结束即清除
- **给主人分享视频**：觉得某个视频适合你时，可发 B站 私信、可在评论区 @、也可两者都发

## 二、真 @ 与评论

- **真 @ 提及**：发评论时带 `at_name_to_mid` 映射，B站 才会把正文里的 `@昵称` 解析成**真实提及并通知对方**。纯文本 @ 不会通知
- **评论复核**：发出后按接口返回的 `rpid` **定点**回查（`wbi/main` + `seek_rpid`），不再赌「还在首页」。
  90 秒先做乐观确认；查不到记 `pending`，10 分钟后再用**匿名 + 登录双视角**判定：匿名查不到、
  登录查得到 = 仅自己可见。所有评论与回复都查，结果写 `comment_verify_log.json`（原始 `state`/`attr` 一并落盘）
- **评论自动回复**：轮询评论通知，自动生成回复
- **@ 通知回复**：有人在视频评论区或动态评论区 @ 它时自动回复
- **动态评论区回复**：在你发布的动态下收到评论也会回复
- **图片识别**：评论里的图片自动识别内容后参与回复
- **视频上下文**：自动获取被评论视频的信息，支持用视觉模型看封面与内容
- **联网查询**：涉及时事、新知、特定事件时判断是否需要联网，支持 Tavily / Firecrawl / Grok（xAI 原生）/ Perplexity / 博查 / 自定义 OpenAI 兼容接口
- **恶意告警**：评论区有人攻击它时，用人设口吻通过 QQ 私信告诉你，你可直接回复决定是否拉黑

## 三、私信与直播

- **B站 私信回复**：监听纯文字与视频分享私信；可后台查 UP / 视频或联网搜索，先短回应、查完再整合，最多两条；发送 `new` 重置当前私信上下文
- **私信安全隔离**：不明外链、IP 链接、疑似色情引流不进 LLM，可自动调用 B站 拉黑；支持只回复主人 / 白名单 / 全部安全用户
- **直播间弹幕互动**：可进入自己或别的主播的指定直播间，读取新弹幕并结合人设、UID 画像、直播记忆生成短回应，用自己的 B站 账号发回同一直播间

## 四、记忆与人格

- **语义记忆**：Embedding 向量化 + 余弦相似度检索，支持记忆压缩与永久记忆
- **好感度系统**：陌生人 → 粉丝 → 熟人 → 好友 → 主人，不同等级不同语气；辱骂自动拉黑
- **用户画像**：词条式档案（昵称、喜好、个人信息、标签、印象），含轻量视频关系与直播互动统计
- **心情系统**：每日随机心情 + 节日彩蛋（含农历）
- **性格演化**：实验性，默认关闭并保留历史数据；建议积累真实反馈后再用每周可回滚模式
- **跨插件记忆接口**：直播伴侣等插件可按 B站 UID 读取画像 / 语义记忆，并写入可检索的直播记忆
- **QQ ↔ B站 记忆互通**：默认关闭。`bili绑定 <UID>` 绑定主人 + 开启安全共享后，QQ 侧只收到脱敏限长的 B站 近期摘要；插件不会反向保存 QQ 聊天记录

## 五、番剧

- **看番系统**：搜索番剧、看详情、完整观看单集
- **字幕 + 热评分析**：读字幕、热评、评论区与用户评价后做 AI 分析
- **番剧记忆**：看完自动生成，`bili番剧记忆` 查询
- **自动追番**：评分到阈值自动加入追番
- **更新查询**：查正在追的番剧是否更新
- **QQ 聊天看番**：在 QQ 里直接让它「去看番」

## 六、让模型调用（LLM 工具）

聊天里用自然语言就能触发，结果回到模型后由它自己转述：

- `bili_recall` — 查画像 / 对话 / 今日活动 / 视频 / 动态 / 番剧记忆
- `search_bilibili` — 搜视频、用户、UP 详情、关注更新与直播
- 看视频 — 分析内容、评分、存入记忆，可链式点赞 / 投币 / 收藏 / 评论
- `bili_action` — 执行点赞 / 投币 / 收藏 / 关注 / 评论（需你同意）
- `bili_bangumi` — 番剧搜索、详情、观看、新番时间线、排行、追番更新
- `watch_and_share_video_private` — 看完后把原生视频卡片发给主人（默认关闭）
- B站 拉黑 — 你确认后拉黑指定 UID
- `bili_parse_video` — 解析群聊 / 私聊里的 B站 链接，可按需下载并发送视频或切片

默认只注册 8 个职责清晰的工具；开启私信分享时 9 个。

## 七、看过的视频（页面）

AstrBot WebUI 里本插件自带一个页面：

- **封面卡片墙**，按时间倒序
- **筛选**：分数区间、心情、来源（收藏夹 / 关注 / 搜索 / 视频池）、是否推荐过、是否评价失败、关键词
- **分页**与**详情抽屉**：评论原话、展开理由、动作明细、分析依据
- 数据源是 `watch_log.json`：主文件保留最近 **500** 条，更早的按月归档在
  `data/watch_log_archive/YYYY-MM.json`，页面读的是归档 + 主文件的全量

## 八、看多细，你决定

`ANALYSIS_DEPTH` 五档：

| 档位 | 视觉分析 | 分段 | 帧 | 每日 token | 字幕上限 | 结果上限 |
|---|---|---|---|---|---|---|
| `subtitle_only` 只看字幕 | 不做 | 0 | 0 | 20k | 6000 | 3000 |
| `lean` 省 token | 按需 | 3 | 4 | 20k | 1500 | 1200 |
| `standard` 标准 | 按需 | 10 | 8 | 50k | 1500 | 1600 |
| `deep` 看更细 | 总是 | 20 | 16 | 150k | 6000 | 3000 |
| `custom` 自定义 | 读单项配置 | — | — | — | — | — |

`standard` 与旧版行为逐项一致。非 `custom` 档时预设覆盖单项配置。

## 九、其它底层行为

- **候选去重**：同一 BV 只留播放量最高那条（总是生效）；标题高度相似的可选合并（`DEDUPE_SIMILAR_TITLES`，默认关）
- **风控 412**：B站 返回 HTTP 412 时不当作网络错误重试，直接清 WBI 缓存并给出可识别错误码
- **先落账后互动**：评分一出就先写 `watch_log`，后面互动失败也不会丢「看过什么」
- **周总结卡片**：从真实记录挑本周值得记住的片段，生成自然周记并渲染成自适应 PNG，QQ / B站 动态优先发图
- **自动发动态**：定时发布，支持 OpenAI 兼容接口生成配图；手动 `/bili动态` 也可用 NovelAI
- **三种模型分工**：总结、生成、日程可分别指定模型；全留空时沿用 AstrBot 默认聊天模型
- **自定义代理**：`PROXY_URL` 支持 http / socks5 / socks5h，只影响本插件的请求
- **LLM 熔断**：连续 5 次失败冷却 2 分钟，恢复时只放行一次探测
- **基础防注入**：可疑 prompt 注入内容检测、记录与安全包裹
- **Cookie 自动刷新** + 扫码登录
- **拉黑管理**：手动 / 自动拉黑；黑名单用户不调模型、不花钱
- **视频直读多格式**：支持 Gemini / Qwen 两种接口格式

## 快速开始

1. 把本仓库放进 AstrBot 的 `data/plugins/astrbot_plugin_bili_scroll`
2. 重载插件
3. 填必填配置（下表）
4. QQ 里发 `bili主动` 跑一轮

### 必填

| 配置 | 说明 |
|---|---|
| `SESSDATA` / `BILI_JCT` | B站 登录态，用 `bili登录` 扫码获取。**扫码一次长期复用**，反复登录会累积风控 |
| `OWNER_BILI_NAME` | 你的 B站 昵称，用于真实 @ 提及 |
| `OWNER_MID` | 你的 B站 UID，与昵称配对 |
| `ENABLE_PROACTIVE` | 主动看片总开关，**默认关** |

可选：`OWNER_QQ_UMO`（推荐私信地址，用 `biliUMO` 取）、
`PROACTIVE_FAV_FOLDERS`（收藏夹投喂池，填 media_id 或收藏夹链接，留空不启用）。

## 已知限制

- 评论复核是后台任务（跨 90 秒 + 10 分钟两次等待），**进程重启会丢**待确认的那条
- 「仅自己可见」的判据里，`attr` 位图与 `state=11/18` 来自第三方实测、没有官方文档；原始值原样落盘，B站 改值后可回溯
- 「审核中」没有独立字段，会和 ShadowBan 混在一起，两者都显示为 `self_only`
